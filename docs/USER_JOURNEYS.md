## 🔐 Authentication Module

### Journey 1: User Login
**Description:** Authenticate an existing user with email and password, with optional MFA verification.

| Step | Action | Preconditions | Postconditions |
|------|--------|---------------|----------------|
| 1 | Navigate to `/login` | User is not authenticated | Login page displayed |
| 2 | Enter email and password | Valid user account exists | Credentials submitted |
| 3 | System validates credentials | - | Authentication checked against Supabase |
| 4 | (If MFA enabled) Enter TOTP code | MFA factor configured | MFA verification completed |
| 5 | System checks password expiry | User authenticated | Redirect to change password if expired |
| 6 | Redirect to dashboard | All checks passed | User session established |

### Journey 2: User Signup
**Description:** Create a new user account with email, password, and profile information.

| Step | Action | Preconditions | Postconditions |
|------|--------|---------------|----------------|
| 1 | Navigate to `/login` and select "Sign Up" tab | - | Signup form displayed |
| 2 | Enter first name, last name, email | - | Profile data captured |
| 3 | Enter password | - | Password strength indicator shown |
| 4 | System validates password strength | Password meets requirements | Validation passed |
| 5 | Submit signup form | All fields valid | Account created in Supabase |
| 6 | Receive confirmation | - | User can now log in |

### Journey 3: Change Password
**Description:** Allow users to change their password, either voluntarily or when forced due to expiry.

| Step | Action | Preconditions | Postconditions |
|------|--------|---------------|----------------|
| 1 | Navigate to `/change-password` | User authenticated (or forced redirect) | Password change form displayed |
| 2 | Enter current password (if not forced) | - | Current password verified |
| 3 | Enter new password | - | Password strength validated |
| 4 | Confirm new password | Passwords match | Confirmation validated |
| 5 | Submit password change | All validations pass | Password updated in Supabase |
| 6 | Record in password history | - | Audit log created |
| 7 | Redirect to dashboard | - | User can continue working |

### Journey 4: MFA Enrollment
**Description:** Set up multi-factor authentication for enhanced account security.

| Step | Action | Preconditions | Postconditions |
|------|--------|---------------|----------------|
| 1 | Access security settings | User authenticated | MFA enrollment option visible |
| 2 | Initiate MFA enrollment | MFA not yet configured | QR code generated |
| 3 | Scan QR code with authenticator app | Authenticator app installed | TOTP secret stored |
| 4 | Enter verification code | Code generated by app | Factor verified |
| 5 | MFA enabled | Verification successful | Future logins require MFA |
